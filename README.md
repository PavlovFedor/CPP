# Проекты по C++

# 1) system-programming-labs
Данная папка содержит выполненные лабораторные работы по курсу «Операционные системы» / «Системное программирование». Все программы написаны на C++ с использованием WinAPI.

## Содержание
- **Лабораторная 1** – работа с файловой системой: получение информации о дисках, копирование файла с заданной позиции.

- **Лабораторная 2** – управление виртуальной памятью: резервирование и выделение страниц, VirtualAlloc, VirtualQuery, VirtualFree.

- **Лабораторная 3** – работа с кучей процесса: динамическое выделение памяти под строки «рваного» массива, сортировка строк по их длине.

- **Лабораторная 4** – процессы и потоки: создание процессов (calc, notepad), приостановка/возобновление потоков, завершение процесса.

- **Лабораторная 5** – синхронизация потоков: вывод фраз из двух потоков, проблема гонки данных, решение с помощью критической секции и мьютекса.

# programming-cpp
В данной папке представлены выполненные лабораторные работы в рамках курса **«Программирование на C++»**. Код написан на C++ (с использованием стандартной библиотеки, STL, а также собственных классов).

## Что реализовано
- **Лабораторная работа №1** – обработка текстового файла: чтение посимвольно, выделение предложений, удаление предложений, содержащих запятые, динамическое выделение памяти, работа с указателями.

- **Лабораторная работа №2** – перегрузка функций (overloading): функции для вывода символов с разным количеством параметров, перегруженные функции поиска минимума в массиве (int, double), шаблонная функция, функция с переменным числом параметров (макрос `...`) для вычисления среднего арифметического элементов на чётных позициях.

- **Лабораторная работа №3** – обработка CSV-файла (данные World Happiness Report). Парсинг строк, извлечение столбцов, анализ показателей (продолжительность здоровой жизни, щедрость, социальная поддержка), вывод стран с заданными условиями, запись результатов в файл.

- **Лабораторная работа №4** – работа с вектором (STL `vector`): генерация случайных чисел, изменение размера, добавление элемента в конец (`push_back`), удаление элемента с произвольной позиции (`erase`), вывод информации о количестве элементов.

- **Лабораторная работа №5** – сортировка массива (метод выбора), работа с текстовым файлом: чтение слов, удаление знаков пунктуации, вывод уникальных слов (с использованием `multimap`), учёт регистра.

- **Лабораторная работа №6** – класс `AB` (пользователь сайта). Конструкторы, деструктор, конструктор копирования, методы для расчёта среднего времени на сайте, процента реализованной прибыли, перевода секунд в дни/часы/минуты. Демонстрация передачи объекта по значению.

- **Лабораторная работа №7** – класс `tomato` (треугольник по координатам вершин). Перегрузка операторов: `<`, `>`, `==`, `+` (сдвиг по X), `+=`. Вычисление площади треугольника по формуле Гаусса.

- **Лабораторная работа №8** – наследование и полиморфизм. Базовый класс `Shape`, производные: `Square`, `Circle`, `Triangle`. Виртуальные методы `Per()` (вычисление периметра) и `GetPer()` (вывод информации). Подсчёт количества созданных объектов (статический счётчик). Динамическое создание массива указателей на базовый класс.
